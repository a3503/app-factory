## Verification Checklist

When verifying policies (monthly), check:

### Google Play
- [ ] Read Policy Updates page for new announcements
- [ ] Check Play Console inbox for policy emails
- [ ] Review Android Developers Blog recent posts
- [ ] Verify target SDK requirements still current
- [ ] Check data safety requirements unchanged
- [ ] Review closed testing requirements

### App Store
- [ ] Read Upcoming Requirements page
- [ ] Check Apple Developer News
- [ ] Verify Xcode/SDK requirements still current
- [ ] Review any guideline section changes
- [ ] Check privacy manifest requirements

### AdMob
- [ ] Check AdMob Help Center for updates
- [ ] Verify SDK versions still supported
- [ ] Review consent requirements
- [ ] Check for new ad format policies

## Compliance Calendar

### Recurring
- **1st of month**: Full policy verification all platforms
- **15th of month**: Quick check for urgent updates
- **Before release**: Re-verify all applicable policies

### Key Annual Events
- **WWDC (June)**: New iOS SDK requirements announced
- **Google I/O (May)**: New Android SDK requirements announced
- **August 31**: Google Play target SDK deadline (typical)
- **April**: Apple typically announces Xcode requirements for fall

## Notes

- Always verify policy changes against official sources, not third-party summaries
- When in doubt, contact platform support for clarification
- Document exemptions or special considerations for specific apps
- Keep screenshots/archives of policy versions for dispute resolution
